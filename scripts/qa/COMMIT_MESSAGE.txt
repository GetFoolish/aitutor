Add automated QA system with cmux browser integration

Implements fast pre-flight QA checks to catch regressions before manual testing.
System runs 5 critical checks in < 30 seconds.

## Features

- cmux browser automation wrapper (372 lines)
- 5 check modules targeting recurring bugs:
  * Empty answer validation bypass
  * Mobile viewport layout collapse
  * MongoDB connection timeouts
  * State management leaks
  * Visual regression detection
- QA orchestrator with colored terminal output
- Shell entry point with service health checks
- Comprehensive documentation (428 lines)

## Usage

```bash
# Run pre-flight checks
./scripts/qa/preflight.sh

# Auto-run with services
RUN_PREFLIGHT_QA=1 ./run_tutor.sh
```
