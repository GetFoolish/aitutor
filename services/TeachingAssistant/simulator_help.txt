================================================================================
                    AI TUTOR CONVERSATION SIMULATOR
                            User Guide
================================================================================

OVERVIEW
--------
The Conversation Simulator processes sample conversation files and integrates
with the Teaching Assistant memory system. It simulates conversations between
a student and AI tutor "Adam" without requiring a live LLM connection.

All text is read from JSON files in Memory_Brief/sample_conversations_for_testing/
and memory events are sent to the Teaching Assistant via WebSocket (same format
as server.js).

The simulator creates a WebSocket server that TeachingAssistant connects to,
allowing it to receive and process conversation events for memory testing.

PREREQUISITES
-------------
1. Teaching Assistant API must be running
    - Start api.py file separately first
    - Command: python services/TeachingAssistant/api.py
    - TeachingAssistant will automatically connect to simulator's WebSocket server
    - No .env file changes needed (default port 8767 matches)

2. Sample conversation files must exist in:
   Memory_Brief/sample_conversations_for_testing/
3. Required files:
   - session_1_intro.md
   - session_2_post_test.md
   - session_3_emotional.md
   - session_4_deep_personal_connection.md
   - session_5_testing_sentient_feel.md

MODES
-----

Mode 1: AUTOMATIC
-----------------
Description: Automatically processes all conversation files sequentially.
            - Reads both Adam and User text from JSON files
            - Processes all turns automatically
            - Waits between files (default: 60 seconds)
            - No user interaction required

Command:
    python services/TeachingAssistant/Simulator.py --mode automatic

With options:
    python services/TeachingAssistant/Simulator.py --mode automatic --delay 120 --user-id student_001

Use Case: Testing memory system with full conversation sessions automatically


Mode 2: INTERACTIVE MIXED (Manual Mode)
----------------------------------------
Description: Interactive/manual mode where you control user responses.
            - Adam's responses: Automatically read from JSON conversation files
            - User's responses: You choose between JSON text or custom input
            - Perfect for testing specific scenarios or customizing conversations

How It Works:
1. Simulator reads conversation files and shows Adam's response
2. Shows suggested user text from JSON file
3. You can either:
   - Press Enter (empty input) → Uses the JSON text automatically
   - Type your own response → Uses your custom text instead
4. Process continues to next turn
5. Type 'quit', 'exit', or 'q' to end the session early

Command:
    python services/TeachingAssistant/Simulator.py --mode interactive_mixed

With options:
    python services/TeachingAssistant/Simulator.py --mode interactive_mixed --user-id my_user

Example Session Flow:
    [Turn 1/39]
    Adam > Just okay? Rough day at school?
    JSON User > hey. uh, i'm okay i guess....
    
    Press Enter to use JSON text, or type your own response: 
    [Press Enter] → Uses "hey. uh, i'm okay i guess...."
    
    OR
    
    Press Enter to use JSON text, or type your own response: I'm actually doing great!
    [Your custom text] → Uses "I'm actually doing great!"

Use Cases:
- Testing memory system with custom user responses
- Simulating specific conversation scenarios
- Mixing automatic (JSON) and manual (custom) responses
- Testing how TeachingAssistant handles unexpected inputs
- Debugging specific conversation flows


COMMAND-LINE OPTIONS
--------------------

--mode {automatic,interactive_mixed}
    Simulation mode to run
    Default: automatic

--user-id USER_ID
    User ID for the simulation
    Default: simulator_user

--delay SECONDS
    Delay in seconds between files in automatic mode
    Default: 60

--ws-port PORT
    WebSocket server port for TeachingAssistant to connect to
    Default: 8767 (matches TeachingAssistant default, no .env changes needed)


EXAMPLES
--------

# Run automatic mode with default settings
python services/TeachingAssistant/Simulator.py

# Run automatic mode with 2-minute delay between files
python services/TeachingAssistant/Simulator.py --mode automatic --delay 120

# Run interactive mixed mode (manual mode - Enter for JSON, or type custom)
python services/TeachingAssistant/Simulator.py --mode interactive_mixed

# Run interactive mixed mode with custom user ID
python services/TeachingAssistant/Simulator.py --mode interactive_mixed --user-id student_001

# Manual mode workflow:
# 1. Start simulator in interactive_mixed mode
# 2. For each turn, you'll see:
#    - Adam's response (from JSON file)
#    - Suggested user text (from JSON file)
# 3. Choose your action:
#    - Press Enter → Use JSON text (quick, automatic)
#    - Type custom text → Use your own response (manual control)
#    - Type 'quit' → End session early

# Full example with all options
python services/TeachingAssistant/Simulator.py --mode automatic --user-id test_user --delay 90 --ws-port 8767


MEMORY INTEGRATION
------------------
The simulator integrates with the Teaching Assistant memory system via WebSocket:

1. Session Start: Sends session_start event (triggers session initialization)
2. User Turn: Sends text event with speaker="user" (triggers TA-light retrieval)
3. Adam Turn: Sends text event with speaker="adam" (completes turn for memory extraction)
4. Session End: Sends session_end event (triggers memory consolidation)

Memory Files Created:
- TA-light-retrieval.json: Light retrieval results (every turn)
- TA-deep-retrieval.json: Deep retrieval results (every 3 turns)
- TA-closing-retrieval.json: Session closing summaries
- academic.json: Academic memories
- personal.json: Personal memories
- preference.json: Preference memories
- context.json: Context memories

Location: services/TeachingAssistant/Memory/data/{user_id}/memory/


TROUBLESHOOTING
---------------

Problem: "No TeachingAssistant clients connected"
Solution: Make sure Teaching Assistant API is running and has connected
    1. Start API: python services/TeachingAssistant/api.py
    2. Check that TeachingAssistant connects to WebSocket server
    3. Verify port matches (default: 8767)
    4. If using custom port, set TUTOR_WS_URL=ws://localhost:{port}/ta in .env

Problem: "File not found" errors
Solution: Verify conversation files exist in:
    Memory_Brief/sample_conversations_for_testing/

Problem: No TA-light or TA-deep files created
Solution: 
    1. Check TeachingAssistant is running and connected to simulator
    2. Verify session_start event was received successfully
    3. Check terminal for [RETRIEVAL] logs in TeachingAssistant output
    4. Ensure memory retriever is initialized

Problem: Port already in use
Solution:
    1. Check if another service is using port 8767
    2. Use --ws-port to specify a different port
    3. If using custom port, configure TeachingAssistant with matching TUTOR_WS_URL


QUICK START
-----------

Automatic Mode:
1. Start Teaching Assistant API:
   python services/TeachingAssistant/api.py

2. In another terminal, run simulator:
   python services/TeachingAssistant/Simulator.py --mode automatic

3. Monitor terminal output for:
   - [RETRIEVAL] logs (TA-light/TA-deep working)
   - [MEMORY] logs (memory extraction working)
   - ✅ Success messages

4. Check memory files in:
   services/TeachingAssistant/Memory/data/{user_id}/memory/

Manual/Interactive Mode:
1. Start Teaching Assistant API:
   python services/TeachingAssistant/api.py

2. In another terminal, run simulator:
   python services/TeachingAssistant/Simulator.py --mode interactive_mixed

3. For each conversation turn:
   - Read Adam's response (displayed automatically)
   - See suggested user text from JSON file
   - Press Enter to use JSON text, OR type your own response
   - Type 'quit' to end session early

4. Monitor terminal output for:
   - Conversation turns and your input choices
   - [RETRIEVAL] logs in TeachingAssistant terminal
   - Memory processing confirmation

5. Check memory files in:
   services/TeachingAssistant/Memory/data/{user_id}/memory/
